#  CyberBeat:

##  项目简介
* **游戏类型**：第三人称赛博朋克动作角色扮演游戏（ARPG Demo）
* **开发周期**：约 2 个月
* **项目职责**：全流程开发（包含心率 API 接入、核心逻辑编写、状态机架构、关卡设计与视觉后处理调优）
* **核心玩法**：游戏将玩家的真实生理反馈（实时心率 BPM）深度融入战斗逻辑。通过**长短时间窗口算法**计算玩家的基准心率与波动，实现三种心率状态（Normal / Recovering / High Stress）的动态切换，联动攻击数值、技能解锁、全屏色散与边缘红框等视觉反馈，打造生理与战斗双重沉浸的体验。

---

##  运行环境与技术栈
* **引擎版本**：Unity 2021.3.45
* **开发语言**：C#
* **渲染管线**：Universal Render Pipeline
* **核心技术/架构**：
  * **Event-Driven Architecture**：基于观察者模式构建事件驱动架构，使心率核心模块与 UI、视觉后处理、音效及敌方 AI 相互独立。
  * **Mathf.Lerp 非线性插值**：平滑控制高压状态下的后处理参数，避免视效突变引起眩晕。
  * **API**：支持心率广播协议接入真实心率设备。
